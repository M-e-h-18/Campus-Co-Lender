# Campus Co-Lender

Campus Co-Lender is a web application for campus communities to buy, sell, and express interest in second-hand products, books, and goods. The platform allows users to list products, mark products as "interested," communicate with sellers, and manage their own listings—all in a secure, peer-to-peer environment.

---

## 🚩 Branch: `update1`

This branch includes the latest enhancements for managing product interests, notifications, and user listings.

---

## ✨ Features

- **Product Listings:** Users can add, view, and manage products for sale.
- **Interest System:** Express interest in products, track interested items, and view interested users for each listing.
- **User Authentication:** Secure login and registration.
- **Personalized Dashboard:** Quickly access your listings, interested products, and messages.
- **Search and Filter:** Find products easily with search and filter options.
- **Notifications:** Sellers are notified when someone expresses interest in their product.
- **Responsive Design:** Mobile-friendly and visually appealing layouts.

---

## 🛠️ Technology Stack

- **Backend:** Python, Flask, SQLAlchemy
- **Frontend:** HTML, CSS (Bootstrap), JavaScript
- **Database:** MySQL
- **User Authentication:** Flask-Login

## 🚀 Getting Started

1. **Clone the repository:**
    ```bash
    git clone https://github.com/M-e-h-18/Campus-Co-Lender.git
    git checkout update1
    cd Campus-Co-Lender
    ```
2. **Install dependencies:**
    ```bash
    pip install -r requirements.txt
    ```
3. **Set up configuration:**
    - Add database credentials and secret keys to a `.env` file.

4. **Run the application:**
    ```bash
    flask run
    ```
